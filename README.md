
# Text-to-Speech Application

A web-based Text-to-Speech application that converts written text into speech using multiple languages and voices.

## Features

- Text-to-Speech conversion
- English, Hindi, Marathi, and German support
- Male and female voices
- Audio playback and download
- User authentication
- Speech history and favorites

## Technologies Used

- React.js, Vite, Tailwind CSS
- Node.js, Express.js
- Python, edge-tts
- Supabase
- Vercel and Render
